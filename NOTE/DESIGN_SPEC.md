# 毛玻璃登录界面设计规范

本规范记录 HTML 原型和 QML 实现的视觉意图。SDDM 兼容性约束优先于视觉效果；
具体数值以 `prototype/styles.css`、`theme.conf` 和 `Main.qml` 为准。

## 设计方向

界面以壁纸为环境层，左侧是一条贴边毛玻璃，右侧保留壁纸和纯文字时间。目标
是安静、轻盈、清晰且有边界的登录画面，而不是普通网页表单或后台页面。

## 核心原则

- 密码输入和“登录”是唯一主操作；账户、会话、电源和辅助提示依次降低层级。
- 一页只使用一个实色主按钮，不继续放大标题、时钟或系统按钮。
- 间距、字号、颜色、圆角和动效统一使用设计 token，不在页面中散落一次性数值。
- 左侧保留充足留白，组外间距应明显大于组内间距。
- 彩色壁纸使用带粉紫倾向的浅色文字，并以深色玻璃保证对比度，不使用中性灰。
- 状态不能只依赖颜色；焦点、选中和错误同时使用轮廓或文字表达。

## 页面结构

- 毛玻璃从屏幕顶部延伸到底部，右侧直接结束，不使用渐隐或竖向分割线。
- 登录内容在左侧水平、垂直居中；用户名只显示一次，头像与名称纵向排列。
- 用户名称下方使用与登录胶囊同宽的细横线，并显示按时段变化的问候。
- 右侧保留大面积壁纸，时间以纯文字贴近底部分区线，不增加卡片或边框。
- 页脚用横向分区线分隔：左侧依次为“切换用户”和会话控件，右侧为日期和星期。
- 两个页脚菜单都向上展开并与各自触发器对齐；窄屏时保持顺序，避免菜单溢出。
- 窄屏时毛玻璃覆盖全屏，保持简洁，不增加新的卡片层级。

登录控件宽约 `312px`。密码胶囊高 `44px`，登录按钮高 `40px`；三个电源操作
与登录胶囊等宽，使用 `48px` 图标框和 `24px` 图标。头像主体 `112px`，外围
使用约 `6px` 强调色圆环和 `2px` 黑色内环，与名称之间保留足够净空。

## 视觉系统

以 `4px` 为间距基础单位，正文只使用 `400`、`500`、`600` 三档字重。玻璃
顶部保留细亮边，底部使用短而柔和的阴影，不额外堆叠发光描边。

大块表面只用于贴边毛玻璃，弹出菜单可以作为小毛玻璃卡片。时间区、背景和
页脚不加卡片。不得通过提高暗色遮罩换取模糊感，优先调整模糊强度、饱和度和
背景构图。

HTML 原型使用 `34rem` 宽的侧栏，QML 在 16:9 下使用 `608px` 设计宽度；两者
分别按自身画布校准，不要求像素宽度一致。

## 颜色

后备色使用 `theme.conf` 中的低饱和粉紫色板。greeter 启动时采样一次壁纸，
生成强调色、玻璃色调以及控件和弹窗的深色表面；采样失败或关闭 `autoColors`
时使用固定后备色。`autoSurfaceColors=false` 只关闭控件表面自动取色。

文字、错误色和主按钮文字保持固定，普通文字对比度不低于 WCAG AA 的
`4.5:1`。自动取色不得覆盖这些可读性约束。

## 动效与交互

首次打开或刷新时，登录区域直接呈现，不播放整页淡入、上浮或缩放动画。菜单、
对话框和密码显隐可以使用短时过渡，动画只用于解释用户主动触发的状态变化，
并尊重 `prefers-reduced-motion`。

电源确认弹窗支持取消、`Esc` 和点击外部关闭，只有明确选择“继续”才执行危险
操作。功能键支持 `Enter`/`Space`，默认焦点位于“取消”。会话和用户菜单必须
同时支持鼠标、键盘和清晰的焦点状态。

## QML 边界

HTML 的 `backdrop-filter` 只用于原型。QML 通过 `ShaderEffectSource` 和
`MultiEffect` 实时模糊左侧壁纸，不引入 `Qt5Compat.GraphicalEffects`。

头像使用 `MultiEffect` 圆形遮罩；图片不可用或效果不可用时显示姓名首字母。
会话菜单使用 `Repeater` 和基础列表类型读取 `sessionModel` 的 `name` 角色，
不使用缺少箭头的 `SddmComponents.ComboBox`。

HTML 只用于确认布局、层级和色彩。真实交互、键盘焦点和登录行为必须使用
`make preview` 在 SDDM greeter 中验证。
