# 毛玻璃登录界面设计规范

本规范用于 HTML 布局原型和当前 QML 实现。优先级低于 SDDM 兼容性约束：
任何设计效果都不得引入约定外的 QML 模块或导致 greeter fallback。

## 设计方向

界面以壁纸为环境层，左侧是一整条贴边毛玻璃，登录内容在左侧水平、垂直居中。
右侧只保留壁纸和纯文字时间。视觉目标是一个安静的 SDDM 登录画面，而不是
浏览器表单或通用后台页面。

关键词：安静、轻盈、清晰、有边界。

## 十二条原则的项目化解释

1. 层级：密码输入和“登录”是唯一主操作；账户与会话次之；电源与辅助提示
   保持三级。
2. 突出主操作：压低标题、时钟和系统按钮的对比度，不继续放大登录按钮。
3. 数值系统：间距、字号、色值、圆角、模糊和阴影全部来自 CSS token；QML
   实现时对应写入 `theme.conf` 或集中常量。
4. 留白：左侧毛玻璃内部保留充足呼吸区，减少文字和装饰，不压缩控件间距。
5. 分组：组外间距使用 `24/32/48px`，组内间距使用 `8/12/16px`。
6. 文字层级：正文只使用 400、500、600 三档字重，以及主文字、次文字、
   辅助文字三档同色相颜色。
7. 彩色壁纸：不在彩色背景上使用中性灰文字；使用带粉紫倾向的浅色文字，
   并通过深色玻璃和背景遮罩降低亮度，而不是直接给白字加透明度。
8. 操作分级：一页只有一个实色主按钮；会话、显示密码和电源操作保持低层级。
9. 语义元素：HTML 原型可以使用 `main`、`section`、`form`、`label` 和
   `button`，但视觉上不得呈现为普通网页表单。
10. 光感：玻璃顶部有细亮边，底部有短而柔和的深阴影；不额外堆叠发光描边。
11. 行长：说明文字限制在约 28em，标题行长更短，避免大屏横向扫读。
12. 非颜色信号：当前会话同时使用勾选图形和 `aria-checked`；焦点使用轮廓，
    错误与操作状态使用文字说明。

## 严重度

### P0：阻断交付

- QML 导入、属性类型或资源路径导致 SDDM fallback。
- 登录输入、主操作或状态提示无法看清、无法操作。
- 文字对比度低于 WCAG AA，焦点不可见。
- 密码、会话或账户信息出现裁切并影响登录。

### P1：交付前修复

- 使用系统 token 之外的一次性数值。
- 组外间距不大于组内间距。
- 彩色背景上使用中性灰文字。
- 主、次、辅助操作没有明确分级。
- 毛玻璃只有透明色而没有背景模糊或边缘光感。

### P2：发布前打磨

- 标题、时钟或装饰争夺登录焦点。
- 控件看起来仍像浏览器默认样式。
- 动效没有服务状态反馈，或未尊重减少动态效果设置。
- 大屏留白、窄屏换行和头像比例仍需微调。

## 数值系统

### 间距

以 `4px` 为基础单位：

| Token | 数值 | 用途 |
| --- | ---: | --- |
| `--space-1` | 4px | 极紧凑内部间隔 |
| `--space-2` | 8px | 图标与文字 |
| `--space-3` | 12px | 控件内部 |
| `--space-4` | 16px | 组内标准间距 |
| `--space-6` | 24px | 小组间距 |
| `--space-8` | 32px | 主要区块间距 |
| `--space-12` | 48px | 组间间距 |
| `--space-16` | 64px | 页面主区块间距 |
| `--space-24` | 96px | 页面外边距 |

### 字号与字重

| Token | 数值 | 用途 |
| --- | ---: | --- |
| `--text-xs` | 12px | 标签、辅助提示 |
| `--text-sm` | 14px | 次级操作 |
| `--text-md` | 16px | 正文、输入框 |
| `--text-lg` | 20px | 用户名称、登录按钮 |
| `--text-xl` | 28px | 强调文字 |
| `--text-2xl` | 40px | 次级大标题 |
| `--text-clock` | 72px | 右下角时间 |
| `--weight-regular` | 400 | 正文 |
| `--weight-medium` | 500 | 强调 |
| `--weight-semibold` | 600 | 标题和主操作 |

QML 中所有 `font.pixelSize` 必须使用整数，禁止 `10.5`、`14.4` 等值。

### 形状、模糊和动效

| Token | 数值 | 用途 |
| --- | ---: | --- |
| `--radius-sm` | 8px | 小型控件 |
| `--radius-md` | 12px | 菜单选项、功能键 |
| `--radius-lg` | 16px | 弹出菜单、确认对话框 |
| `--radius-pill` | 999px | 头像、密码和登录胶囊 |
| `--blur-rail` | 12px | HTML 原型的左侧模糊 |
| `--blur-menu` | 24px | 弹出菜单玻璃 |
| `--blur-backdrop` | 8px | 对话框背后的背景模糊 |
| `--duration-fast` | 120ms | 按下、焦点 |
| `--duration-normal` | 220ms | 菜单与状态 |

刷新或首次打开界面时，登录内容直接呈现，不执行淡入、位移或缩放等入场动画。
动画只用于用户主动触发的状态变化，例如菜单展开、对话框出现和密码显隐；
关闭菜单、刷新页面和切换主题时不得重复播放装饰性动画。

功能键支持 `Enter`/`Space` 打开确认弹窗。弹窗默认聚焦“取消”，直接按
`Enter` 只会取消；`Tab` 到“继续”后按 `Enter` 才执行操作。

## 颜色

以下固定色板来自随包壁纸的 `3×3` 区域采样，用作自动取色失败时的后备：

```text
上排  #d2afcb  #e0c7de  #dbc4db
中排  #817fa8  #9d91b8  #b49ab3
下排  #646686  #74668e  #887195
```

壁纸通过 Plasma 的“登录屏幕（SDDM）”设置更换。greeter 启动时只采样一次
`64×36` 缩略图，用于强调色、玻璃色调，以及控件表面的同色相深色派生。
输入框、悬停和选中表面分别取约 `HSL L=.25/.30/.34`，弹窗取约
`L=.125`；饱和度限制在 `0.18–0.28`，边框使用主题色低透明度叠加。
文字、错误色和主按钮文字仍保持固定，确保彩色壁纸下可读。设置
`autoSurfaceColors=false` 时保留自动强调色，但控件表面使用固定后备色。

| Token | 参考色 | 用途 |
| --- | --- | --- |
| `--color-text` | `#fff7fc` | 主文字 |
| `--color-text-secondary` | `#e5d5e8` | 次文字 |
| `--color-text-tertiary` | `#e2d7e7` | 辅助文字 |
| `--color-accent` | `#e0c7de` | 主按钮、焦点 |
| `--color-accent-strong` | `#d2afcb` | 悬停 |
| `--color-accent-muted` | `#9d91b8` | 次级强调 |
| `--color-ink` | `#2b1e33` | 实色按钮文字 |
| `--rail-core` | `rgba(45, 30, 53, .22)` | 左侧毛玻璃主体 |
| `--rail-soft` | `rgba(45, 30, 53, .30)` | 毛玻璃右缘 |
| `--color-danger` | `#ffd1d9` | 错误状态 |

不在彩色背景上使用 `#888`、`#aaa` 一类中性灰。

当前 token 在左侧壁纸与毛玻璃复合后的近似背景 `#6a5669` 上的对比度基线：

| 组合 | 对比度 |
| --- | ---: |
| 主文字 / 毛玻璃 | 6.34:1 |
| 次文字 / 毛玻璃 | 4.77:1 |
| 辅助文字 / 毛玻璃 | 4.80:1 |
| 主按钮文字 / 主按钮 | 10.02:1 |
| 主按钮文字 / 悬停按钮 | 8.03:1 |
| 错误文字 / 毛玻璃 | 4.88:1 |

均高于 WCAG AA 对普通文字的 `4.5:1` 要求。

## 布局规则

- QML 设计画布随当前屏幕的逻辑尺寸扩展并缩放，始终覆盖完整屏幕；16:9 时
  保持 `1920×1080` 基准，超宽屏和竖屏不得出现底部或右侧留空。
- 左侧：毛玻璃从屏幕顶边贴到底边，右侧直接结束，不加竖向分割线或渐隐。
- 登录内容：在左侧水平和垂直居中，头像与用户名称纵向居中排列。
- 用户名称只显示一次；不再重复使用 LILY 品牌、装饰标题或“向下延续”文字。
- 用户名称下方使用一条与登录胶囊同宽（`312px`）的细横线，横线后显示
  `16px/500` 的按时间变化问候；用户名和问候语使用与日期相同的柔和文字阴影。
- 右侧：大面积壁纸保持可见，时间使用大字号纯文字贴近底部分区线，不使用卡片或边框。
- 底部：使用一条横向分区线划分主画面和页脚；日期与星期在线下靠右排列，
  使用较大的次级文字增强壁纸上的可读性；“切换用户”和会话胶囊在页脚左端组成
  连续控制组，不显示“当前会话”标签；两个菜单都向上展开。
- 头像主体尺寸 `112px`，外围使用壁纸强调色生成约 `6px` 的纯色圆环，
  并带一层轻微向下的柔和阴影。
- 头像与强调色外环之间保留 `2px` 的纯黑细环。
- 圆环从头像边界向外扩展，内边缘与头像贴合，不覆盖头像内容。
- 系统布局中头像与用户名称间隔 `24px`，圆环向间距内扩展后仍保留 `16px` 净空。
- 密码胶囊约 `312×44px`，提示文字放在输入框内部；输入框尾部使用眼睛图标控制显隐。
- 登录按钮高 `40px`，只使用“登录”文字，不添加右箭头。
- 登录区功能键只保留睡眠、重启和关机，保持第三级：不加分隔线，三项等宽排列，
  圆形描边图标在上方、中文名称在下方。图标框 `48px`、图标本体 `24px`，
  三键整体宽度与密码、登录胶囊同为 `312px`，左右边缘严格对齐；悬停时才加强
  图标圆环。
- 登录表单与功能键间距为 `24px`，不使用上方分隔线。
- 底部“切换用户”在前、会话胶囊在后，二者左对齐并紧邻排列，展开菜单与各自
  触发器对齐。
- 页脚控制组使用统一的 `16px` 间距：左侧留白、组内间隔、按钮到分区线和
  页脚底边的距离保持一致。
- “切换用户”和“当前会话”使用轻边框、半透明底色和图标表达可展开性；
  窄屏仍保持这一顺序，并让会话菜单向右对齐避免溢出。
- 需要删除任何不影响登录、会话或系统操作的装饰性文案。
- 窄屏时左侧毛玻璃覆盖全屏，布局保持简单，不增加新的卡片层级。

## 卡片使用边界

- 大块表面只用于贴边毛玻璃；弹出菜单可以作为小毛玻璃卡片。
- 毛玻璃主体保持接近均匀的半透明色，右侧直接结束，不做渐隐。
- 不得继续提高暗色遮罩来换取模糊感；优先提高背景模糊强度和饱和度。
- 时间区、背景和底部会话条不增加卡片背景或边框。
- 不得用一整块全屏或大尺寸玻璃覆盖壁纸。HTML 原型宽度为 `34rem`；
  当前 QML 使用 `608px` 设计宽度，在 1920 宽屏幕上约占 `31.7%`。

## QML 落地映射

- HTML 的 `backdrop-filter` 只用于原型。QML 使用 `ShaderEffectSource` 和
  `MultiEffect` 模糊左侧壁纸，不引入 `Qt5Compat.GraphicalEffects`。
- QML 启动时把壁纸缩小到 `64×36` 并采样一次，更新强调色、玻璃色调，并
  派生低饱和控件表面和主题色边框。文字、错误状态和主按钮文字保持固定；
  采样失败或关闭 `autoColors` 时回退到 `theme.conf`；仅关闭
  `autoSurfaceColors` 时强调色仍自动更新，控件表面单独回退。
- HTML 仅用于确认布局、层级和色彩。最终交互、键盘焦点和实际登录必须用
  `sddm-greeter-qt6 --test-mode` 验证。
- 用户头像优先使用系统用户模型提供的图标，缺失、加载失败或离屏预览时显示
  用户姓名的首字母。
- 圆形头像使用 `MultiEffect.maskEnabled + maskSource` 裁切，不通过 Canvas
  手动绘制；异步图片加载完成后由场景图自动更新。
- 图标通过 `ThemedIcon` 在支持场景图效果时着色，软件渲染时回退到原始 SVG。
- 壁纸通过 `Qt.resolvedUrl("assets/wallpaper.webp")` 加载，左侧模糊直接采样
  同一个壁纸节点。
- 会话菜单使用 `Repeater`/基础列表类型读取 `sessionModel` 的 `name` 角色，
  不使用缺少箭头的 `SddmComponents.ComboBox`。
