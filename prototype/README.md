# HTML 布局原型

此目录用于快速调整毛玻璃登录界面的布局、层级和色彩，是布局迭代的设计源。
根目录的 `Main.qml` 已同步当前视觉，并负责真实 SDDM 登录、用户和会话选择。

## 预览

使用项目脚本在默认浏览器中打开：

```bash
make prototype
```

也可以手动打开：

```bash
xdg-open "file://$PWD/prototype/index.html"
```

页面使用以下真实项目素材：

- `assets/wallpaper.webp`

## 当前原型范围

- 左侧整条贴边毛玻璃，登录内容水平和垂直居中。
- 只显示一次用户名称 `lily`，没有重复品牌和装饰性说明文字。
- 用户名下方有短横线，并显示按当前时段变化的问候。
- 头像使用姓名首字母和主题色纯色圆环，头像与名字纵向排列。
- 密码使用带眼睛图标的胶囊输入框；登录按钮只保留中文文字。
- 登录区系统功能键只保留睡眠、重启和关机；三键外缘与登录胶囊对齐，
  使用 `48px` 圆形描边图标框和 `24px` 图标，名称位于图标下方。
- 右侧保留大面积壁纸，时间使用大字号纯文字，没有边框或卡片。
- 底部使用横向分区线：时钟位于线上方靠右，日期与星期在线下右侧，
  使用较大字号和更高对比度；“切换用户”与会话胶囊在左下紧邻排列，
  间距与左侧、上下留白统一为 `16px`；“切换用户”和会话菜单都向上展开。
- 切换账户时头像首字母与用户名称同步更新。
- 密码显示切换、会话选择、演示状态和电源确认对话框；点击弹窗外部、取消或
  `Esc` 均可关闭确认弹窗。
- 刷新或首次打开时登录区域直接呈现；只有菜单、对话框和显隐操作使用过渡。
- 所有颜色、字号、间距、圆角、模糊和阴影集中在 `styles.css` 的 token 中。

QML 壁纸通过 Plasma 的“登录屏幕（SDDM）”设置更换，主题色由壁纸自动派生；
HTML 原型使用固定设计 token。

运行检查：

```bash
./scripts/check-prototype.sh
```

## 与 QML 的边界

HTML 的 `backdrop-filter` 只用于布局预览。SDDM QML 使用 `QtQuick.Effects`
实时模糊左侧壁纸。QML 启动时会采样一次壁纸，更新强调色、玻璃色调，并派生
控件表面和主题色边框。HTML 原型不执行运行时取色，仍使用固定设计 token。
